# Braj Ras

Welcome to the Braj Ras landing page repository.

## Overview

Braj Ras is a sacred retreat into the heart of Śrī Vṛndāvan Dhām. Experience the 7 deities, ancient temples, soul-stirring kirtans, and divine pastimes. This landing page is built to capture the essence of the golden trail of Vrindavan with an Awwwards-level interactive and immersive web experience.

## Technology Stack

- react
- vite
- framer-motion & gsap (ScrollTrigger)
- tailwindcss
- typescript
- shadcn/ui

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
